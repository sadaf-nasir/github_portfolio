# github_portfolio
This portfolio contains three projects that I have done, showcasing knowledge/skills in statistics and machine learning. Each folder contains an identical .pdf file and .html file. These are the reports from all projects detailing background, methods, results, discussion, and all code used in the respective projects.

## heart_failure_survival_predictions
A project using random forest models to predict survival in patients with heart failure based on clinical indicators.

## lifestyle_factors_and_well_being
A project exploring the patterns between of lifestyle factors such as sleep, exercise, nutrition, social media use, social connectedness, stress management, time spent in nature and well-being.

## nps_predictions_bank_complaints
A project exploring predictors of customer satisfaction using a random forest regression approach on a dataset of fictional bank complaints.
